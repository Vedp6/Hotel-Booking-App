# 📌 Overview

The **Hotel Booking App** is a full-stack MERN web application that allows users to browse hotels, check room availability, and book rooms online.

This project includes:

- User Authentication
- Hotel Listings
- Room Booking System
- Protected APIs
- Responsive Design
- MongoDB Database Integration
- Admin / Hotel Management Features

# ⚙️ Installation & Setup

# 1️⃣ Clone Repository

```bash
git clone https://github.com/Vedp6/Hotel-Booking-App.git
```

---

# 2️⃣ Navigate to Project

```bash
cd Hotel-Booking-App
```

---

# 3️⃣ Backend Setup

```bash
cd server
npm install
```

---

# 4️⃣ Create `.env` File

Create a `.env` file inside the `server` folder.

```env
PORT=5000

MONGODB_URI=your_mongodb_connection_string

CLERK_SECRET_KEY=your_clerk_secret_key

CLERK_WEBHOOK_SECRET=your_webhook_secret
```

---

# 5️⃣ Start Backend Server

```bash
npm run server
```

---

# 6️⃣ Frontend Setup

Open another terminal:

```bash
cd client
npm install
```

---

# 7️⃣ Start Frontend

```bash
npm run dev
```
